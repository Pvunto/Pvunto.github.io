# Punto — sito personale

Sito statico in italiano per `https://pvunto.github.io/`, realizzato con HTML, CSS e JavaScript senza dipendenze di build.

## Contenuti

- Profilo personale e telecomunicazioni
- Musica e collegamento al profilo Spotify
- Videogiochi con filtri accessibili e trailer ufficiale di THE FINALS
- Archivio visivo dei viaggi e diario di esplorazione
- Pannello radio con configurazione dichiaratamente esemplificativa
- Modellismo, giochi da tavolo, stampa 3D, collezionismo e fumetti

## Pubblicazione

Il repository è configurato per GitHub Pages sul branch `main`, dalla cartella `/`. I file statici nella radice vengono pubblicati automaticamente dopo il push.

Non è richiesto un processo di build. Le immagini originali del sito sono conservate in `assets/`.

Le fotografie personali e le copertine selezionate sono state riutilizzate dai branch `1.0` e `sito-archivio-2026-10-12`; le copie WebP del sito sono ottimizzate e non includono i metadati EXIF delle foto.
